# Правила проекта MD4 Chat Bot

> Не менять без согласования с Сашей. Эти правила существуют, чтобы AI-улучшения не ломали намеренный UX.

## §1. Приветствие новых участников — зафиксировано

**Файл:** `bot/handlers/member_events.py`, обработчик `member_status_event()`, ветка `just_joined`.

**Текст приветствия (не менять):**

```
SUP. Будь любезен, ответь на эти вопросы.👇🏻
И добро пожаловать в 2ch/soc/krsk/пердячка edition
Тян кун?
LVL?
Кто такой? Чем знаменит?
С какого срайона?
Бухаешь или Маваши?
Бабушек через дорогу переводишь?
Хуй сосешь? Пидорас?
```

**Почему так:** Это намеренный формат чата — простой текст, без анкет, без карточек, без Application ID. Не заменять на `questionnaire card`, не добавлять `🧾 Анкета участника`, не пытаться "улучшить" до структурированной анкеты.

**История:** В 2026-08-03 был внедрён полный questionnaire card при join (ID, статус, имя, район и т.д.). Саша откатил — формат слишком корпоративный для этого чата.
